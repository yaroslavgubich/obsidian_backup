Yes, Visual Studio Code provides shortcuts to collapse all functions or code blocks in your file. Here's how you can do it:

### Collapse All Functions or Code Blocks

1. **Windows/Linux:**
    
    - Press `Ctrl + K`, then `Ctrl + 0` (zero).
2. **Mac:**
    
    - Press `Cmd + K`, then `Cmd + 0` (zero).

This shortcut will fold (collapse) all the code regions in the currently open file.

---

### Additional Folding Shortcuts

- **Collapse Current Block:**
    
    - Windows/Linux: `Ctrl + Shift + [`
    - Mac: `Cmd + Option + [`
- **Expand Current Block:**
    
    - Windows/Linux: `Ctrl + Shift + ]`
    - Mac: `Cmd + Option + ]`
- **Expand All:**
    
    - Windows/Linux: `Ctrl + K`, then `Ctrl + J`
    - Mac: `Cmd + K`, then `Cmd + J`

You can customize these shortcuts in the **Keyboard Shortcuts** settings if needed. Access them via:

1. Open Command Palette (`Ctrl + Shift + P` or `Cmd + Shift + P` on Mac).
2. Search for "Preferences: Open Keyboard Shortcuts."
3. Search for "Fold All" or "Unfold All" to customize.
